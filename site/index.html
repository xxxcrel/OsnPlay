Your iPhone.
At home in your car.

Maps, music and conversations on your car display. OsnPlay brings wired and wireless CarPlay to compatible Android head units, with the familiar DiAuto interface.

Download APK ↓How to install

No jailbreak, dongle, account or authentication server required.

Install on the car, not the iPhone. Android 9+; Wi-Fi Direct requires Android 10+. Wireless uses the built-in car hotspot or Wi-Fi Direct. Compatibility depends on the head unit, firmware and iOS version.

These projects focus on BYD cars. They may work on other brands, but other brands are unsupported and there are no plans to add support or fix brand-specific incompatibilities.

Install on your car

  1. While parked, download the APK and install it using the method supported by your head unit.
  2. Open OsnPlay and allow the requested Bluetooth, Wi-Fi/location and microphone permissions.
  3. Turn on the car’s built-in hotspot (5 GHz if available). In Settings → Connection setup, select Built-in car hotspot and save its exact name and password. Keep phone Wi-Fi and Bluetooth on, pair with the car, then tap Connect phone and accept the phone prompts.
  4. For wired use, connect a USB data cable and choose Connect with USB. Approve any USB, Trust or local VPN prompts.

ADB is not required for everyday use. APK installation options depend on the car. No manual MAC address entry.

In this release

  • Preferred Wi-Fi Direct channel for the next connection: Auto remains the default; manual channels need radio/regional support and rejected or mismatched channels report an error. This is not a confirmed stutter fix.
  • Movable custom turn card over the dashboard map, with size choices and 2% position steps. Unknown maneuvers show no guessed arrow; expired guidance clears.
  • Two-, three- or four-finger settings swipes, with three as the default. Android TV/remote controls preserve ordinary head-unit touch and knob behavior.
  • Optional read-only legacy vehicle-data detection; default DiLink 5.0 mode remains the default. Only accepted fields/readings are used, with stale-probe and battery-publication concurrency corrections.
  • Optional automatic startup of the existing car hotspot, off by default, with verified permissions limited to OsnPlay’s own package. Hotspot credentials are preserved.
  • Wireless location/vehicle data use the runtime Wi-Fi link; parked-video availability waits for SETUP/event readiness. Video still requires network ADB and valid P-gear data.
  • Keep artists across partial song updates and publish metadata/artwork only when changed, while playback position and state continue updating.
  • Android 9 audio compatibility, failed-codec cleanup, settled geometry/startup checks after reconnect, guarded Android 10 P2P recovery in Auto mode, and a wired VPN restricted to OsnPlay.
  • Bounded wireless, media, theme and own-app exit diagnostics without audio/video/packet payload recording or automatic uploads.
Release notes & checksums ↗

Before you try it

A public preview, not an Apple-certified product. Authentication uses an experimental accessory identity recovered from public firmware; future acceptance is not guaranteed. Some head units still show stuttering or ignore icon-size changes. Start with 30 fps and HEVC off; try a lower resolution if needed.

Updates & signing

Install over the previous public release to retain settings; the public signing key is unchanged. Test builds use a separate app package.

Please send fresh reports from 0.2.11

If a problem remains, reproduce it on 0.2.11, then open Settings → Diagnostics → Save diagnostic report. Android 10+ saves to Downloads/OsnPlay; Android 9 uses a document picker. Review the .txt file and attach it to your existing GitHub issue with vehicle/firmware, iPhone/iOS, connection mode, steps and failure time. Never post your hotspot password. Qin Plus startup, Wi-Fi Direct stutter, Siri, iOS 15 and day/night firmware reports still need device evidence.
